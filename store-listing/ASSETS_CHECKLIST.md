# Assets Checklist — Images Both Stores Ask For

Make these BEFORE opening the store forms. Tick them off as you finish.
**Rule for all of them: use REAL screenshots of YOUR app on YOUR phone.
Never use fake, downloaded, or edited-to-lie screenshots — both stores
reject apps for that, and it's against their rules.**

---

## 1. App Icon (both stores — same file)

- [ ] **Size: 512 × 512 pixels, PNG**, square, no rounded corners added by
      you (the stores cut the corners themselves).
- The project already has a launcher icon (paper-plane style, Telegram
  blue). If a store asks for a separate 512×512 upload, use a clean export
  of that same icon so the store page matches the phone's home screen.
- Check it at small size: you should still recognise it when it's tiny.

## 2. Screenshots — the plan (same set works for both stores)

Capture **6 phone screenshots**, in this order (stores show them in the
order you upload):

1. Drive screen with some files in it (your hero shot — put this FIRST)
2. Setup wizard Step 1 (BotFather guide — shows how easy setup is)
3. Setup wizard "Find my group automatically" step
4. Upload in progress / file picker choosing a file
5. Folders + search on the Drive screen
6. Notes & links composer, or a file opened/downloaded

### Sizes

- **Your phone's own screenshot size is what you upload** — both stores
  accept standard full-HD phone screenshots. Safe standard size:
  **1080 × 1920 pixels (portrait)**. If your phone captures a taller size
  (for example 1080 × 2400), that is also normally accepted — upload as-is,
  do not stretch or crop screenshots to force a size.
- **Format:** PNG or JPG.
- **Amazon Appstore:** minimum **3 screenshots** required; upload **5–6**.
  Amazon also accepts landscape tablet sizes (for example 1920 × 1200) if
  you target tablets — you do NOT need tablet screenshots for a phone app;
  skip them if the portal lets you.
- **Samsung Galaxy Store:** minimum **4 screenshots** required; upload the
  same **5–6**. Samsung checks that screenshots match your uploaded app —
  another reason they must be real.
- If a portal rejects a screenshot, read its message: it always names the
  size/format it wants. Resize a COPY (never stretch — crop or pad), and
  re-upload.

## 3. Feature / promotional graphic

- **Amazon Appstore:** no separate feature banner is required for a normal
  listing. If Amazon promotes the app later it may ask for a
  **1024 × 500** promotional image — only make it if asked.
- **Samsung Galaxy Store:** no feature graphic is required to submit.
  Samsung may offer an optional promotional/banner slot later
  (commonly **1200 × 675**) — optional, skip it for v1.0.0.
- **Google Play (later):** will require a **feature graphic 1024 × 500 PNG/JPG**
  — note it now so you're not surprised then.

So for v1.0.0 on Amazon + Samsung you only need: **1 icon + 6 screenshots.**

## 4. How to capture the screenshots (simple, honest method)

1. Install `TelegramDrive.apk` from your GitHub Release on your own phone.
2. Run the real setup with YOUR bot and YOUR private group (the wizard —
   2 minutes).
3. Upload 4–5 real files you don't mind being seen in a public store photo
   (for example a photo of a place, a sample PDF, a note saying
   "Welcome to my drive"). ⚠️ Check every screenshot before uploading:
   **no bot token, no personal files, no phone numbers, no private chat
   names** should be visible anywhere. Retake the shot if anything
   private appears.
4. On most Android phones: press **Power + Volume Down** together to take
   a screenshot. Do the wizard shots DURING a fresh setup run (you can
   redo setup from the app's disconnect/reset if you already finished it).
5. Copy the screenshots to the device where you fill the store forms.
6. Upload in the order listed above, drive screen first.

## 5. Final check before submitting anywhere

- [ ] Icon: 512×512 PNG, matches the installed app's icon
- [ ] 6 real phone screenshots, in order, no private data visible
- [ ] Screenshots show the CURRENT version (retake them after big UI changes)
- [ ] Nothing in any image promises things the app can't do
      (no "100% free forever no ads", no fake 5-star badges)
