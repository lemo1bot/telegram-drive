# Telegram Drive — Free Store Listing Pack

Everything you need to publish **Telegram Drive** on the free stores,
written for a first-time publisher. No step here costs money.

## What's inside

| File | What it is |
|---|---|
| `LISTING_COPY.md` | Ready-to-paste title, descriptions, keywords, category, and v1.0.0 release notes for both stores |
| `PRIVACY_POLICY.md` | The complete privacy policy — publish it at a public URL (stores require the link) |
| `AMAZON_APPSTORE_GUIDE.md` | Step-by-step Amazon Appstore submission (free account) |
| `SAMSUNG_GALAXY_STORE_GUIDE.md` | Step-by-step Samsung Galaxy Store submission (free seller account) |
| `ASSETS_CHECKLIST.md` | Every image you need, exact sizes, and how to take real screenshots |

## Do it in this order

1. **GitHub Release first.** Push the app to GitHub and tag `v1.0.0` so the
   Release has the installable **`TelegramDrive.apk`**. Both stores need
   this APK file. (Also: put your own AdMob IDs in the build before this —
   test IDs show ads but earn ₹0. Steps are in the project README.)
2. **Publish the privacy policy link.** Add `PRIVACY_POLICY.md` to the
   GitHub repo and turn on GitHub Pages (Amazon guide, Step 5). Both
   stores ask for this URL.
3. **Take the screenshots** (ASSETS_CHECKLIST.md) — install the APK, do
   the real setup, screenshot the app. Check no token or private file is
   visible.
4. **Amazon Appstore** — follow AMAZON_APPSTORE_GUIDE.md. Free account,
   ~30–45 min, review usually 1–3 business days.
5. **Samsung Galaxy Store** — follow SAMSUNG_GALAXY_STORE_GUIDE.md. Free
   seller account, ~30–45 min, review usually 2–5 business days.
6. **Google Play LAST, later.** Play is the only store that charges
   ($25 one-time developer fee) and the only place the $10 lifetime
   Premium purchase works. Plan: let AdMob ads earn on the free stores
   first, then use earnings to pay the $25 — you never pay from pocket.

## The three honest things to remember

- **Ads earn on Amazon + Samsung. Premium ($10) does not** — it uses
  Google Play Billing, so it only works in the Play version. Both guides
  say exactly what to answer and tell users.
- **Only you can do the identity steps.** Account sign-ups, identity
  verification, and any tax/payment details for payouts must be filled by
  you, with your real details, on the stores' own websites. Never share
  OTPs or passwords with anyone.
- **Never click your own ads** and never use fake screenshots — both get
  accounts banned, for free, forever.
